# vX.Y — 版本规划与变更记录（模板）

> 使用方式：每个版本**复制本文件**为 `vX.Y.md`，先写「功能规划」指导开发，发版时补「变更记录」。
> 规范自 **v2.3** 起执行；v2.2.20 及之前的历史见 [`RELEASE_NOTES.md`](../../RELEASE_NOTES.md)。

```
状态：规划中 / 开发中 / 已发布
目标版本：vX.Y.0
上一版本：vX.Z
规划日期：YYYY-MM-DD
发布日期：YYYY-MM-DD（发版时填）
```

## 一、版本定位

> 一句话说明：这一版解决什么核心问题。避免出现"什么都做一点"的版本。
