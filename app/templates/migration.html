5
收尾工作

  

    
说明：本步仅作用于源库（原主库），回收桥接复制账号 DROP USER IF EXISTS 'replication'@'%' 并把源库置为只读暖备（保留期后再下线）；目标集群（新主）不受影响，仍由 Custos 正常托管。

    
⚠ 警告：「只读」只限制普通账号写入，root / SUPER 仍可写；且它是运行时变量，重启即失效，要永久只读须写进配置文件。源库账号缺 SUPER 权限时本步会如实上报未完成项，不会谎报成功。

  

  

    
    
    
  

  

  
✓ 迁移完成。请在外部手动切换 VIP，源库已置只读暖备。







  

    
确认执行停桥切换？

    
1. 目标停止从源复制（STOP REPLICA）并清除桥接通道。

    
2. 目标节点登记进 Custos 并纳入托管（沿用既有集群，新主不会被移出集群），monitor 自动提升新主、接管其高可用(HA)。

    
3. VIP 需你在外部手动切换（本场景 Custos 不接管 VIP）。

    
4. 操作前请确认校验步骤已通过、复制已追平（SHOW REPLICA STATUS 的 Seconds_Behind_Master≈0）。
