⑤ 收尾回收

  
本步仅作用于源库（老主），绝不改动目标集群（新主 203）。将执行：

    ① 源库执行 DROP USER IF EXISTS 'replication'@'%' —— 回收桥接专用的源端复制账号；

    ② 源库执行 SET GLOBAL read_only=ON —— 将老主置为只读暖备（保留期后下线）。

    目标集群的新主 203 及其从节点（如 213/33）不受影响，仍由 Custos 正常托管。

  

    
    
    
  

  

  
✓ 迁移完成。请在外部手动切换 VIP，老主已置只读暖备。







  

    
确认执行停桥切换？

    
1. 目标停止从源复制（STOP REPLICA）并清除桥接通道。

    
2. 目标节点登记进 Custos（沿用既有集群，新主 203 不会被移出集群），monitor 自动提升新主、接管 HA。

    
3. VIP 需你在外部手动切换（Custos 不自动接管本场景 VIP）。

    
4. 操作前请确认校验步骤已通过、复制已追平（SHOW REPLICA STATUS 的 Seconds_Behind_Master≈0）。
